#  Pong Game — классическая аркадная игра на Python

Простая реализация игры «Пинг-понг» на языке Python с использованием библиотеки Pygame. Игра предназначена для двух игроков на одном компьютере.


##  Управление

| Игрок | Клавиши         | Действие     |
|-------|----------------|--------------|
| Левый | `W` / `S`       | Вверх / Вниз |
| Правый| `↑` / `↓`       | Вверх / Вниз |

##  Как запустить

### 1. Установите Python 3.11

Рекомендуется использовать **Python 3.11**, так как Pygame может быть несовместим с более новыми версиями (3.12–3.14).

Скачать можно здесь:  
[python.org/downloads/release/python-3119](https://www.python.org/downloads/release/python-3119/)  
При установке **обязательно отметьте** `Add Python to PATH`.

### 2. Установите Pygame

Откройте командную строку (терминал) и выполните:

```bash
py -3.11 -m pip install pygame

```bash

### 3. Запуск игры
Перейдите в папку игры в командной строке **cd**
py -3.11 ping-pong.py
